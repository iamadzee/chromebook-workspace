Offline File Vault

Encrypt and carry private files in one password-protected bundle. Create or unlock it right here on your Chromebook—even without internet. No account, upload, storage subscription, or installation.

Your files and password stay in this browser. The vault is encrypted with AES-GCM using a key derived from your password. Choose a long, unique password and keep it safe: there is no password reset or recovery service.

Create an encrypted vault

Names and file contents are encrypted. The bundle can be copied to a USB drive or backed up like any other file.

Unlock a vault

    • Works offline once this page has loaded; encryption and decryption happen on-device.
    • Keep a separate backup of your .crvault file. This tool does not store a copy.
    • Use a different, strong password. Anyone who gets both your vault and password can open it.
    • Large files use your device's memory while processing. For reliability, each file must be 64 MB or smaller and each vault may contain up to 100 files totaling 128 MB.
